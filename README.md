# 法人補完 — 営業リストに法人番号を付けるスプレッドシートツール

Googleスプレッドシートの営業リストに、**法人番号・正式名称・本店所在地**を自動で書き込むツールです(Google Apps Script製)。
社名だけで1社に決められないときは、**候補を全部並べて、サイドバーから選べます**。

## できること

| 機能 | 内容 |
|---|---|
| 自動補完 | 「会社名」列(あれば「URL」「住所」列も)から法人番号を特定して書き込む |
| HPからの絞り込み | URLがあれば会社概要ページを読み、郵便番号・住所・記載された法人番号で候補を絞る |
| 3段階の判定 | 🟢確定 / 🟡要確認 / 🔴該当なし で色分けし、一致度と根拠も書く |
| 候補選択サイドバー | 🟡の行を1件ずつ表示。候補をクリックして確定、該当なし、法人番号の直接入力もできる |
| 補完辞書 | 選んだ結果を「補完辞書」シートに覚え、次回からは同じ会社(同じドメイン)を自動確定 |
| 大量データ | 6分の実行制限を超える分は、1分後に自動で続きを処理 |

## 準備(最初に1回)

1. 対象のスプレッドシートを開き、メニュー **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs` の中身をすべて消し、[`dist/Code.gs`](dist/Code.gs) の中身を貼り付ける
3. 左の「ファイル」の **＋ → HTML** で `Sidebar` という名前のファイルを作り、[`dist/Sidebar.html`](dist/Sidebar.html) の中身を貼り付ける
4. 💾 で保存し、スプレッドシートを再読み込みする → メニューに **🏢 法人補完** が出る
5. **🏢 法人補完 → ⚙ 法人番号APIのIDを設定** で、国税庁のアプリケーションIDを入力する
6. 初回実行時に Google の権限確認が出るので「許可」する

> 他のスプレッドシートで使うときは、ひな形のシートを「ファイル → コピーを作成」すればスクリプトごと複製されます(IDの再設定は必要です)。

## 使い方

1. 1行目に見出しを付ける(列の順番は自由)
   - 必須: `会社名`(企業名・社名・取引先名 でも可)
   - 任意: `URL`(HP・ホームページ でも可)、`住所`(所在地・都道府県 でも可)
2. **🏢 法人補完 → ▶ 補完を実行(このシート)**
3. 右端に「判定・一致度・法人番号(補完)…」の列が追加され、結果が入る
4. 🟡要確認 が残ったら **🟡 要確認の候補を選ぶ** でサイドバーを開き、候補を選んで「確定」

- 使い方は **📖 マニュアルを表示** で「法人補完マニュアル」シートとしていつでも出せます
- 判定をやり直したい行は、行を選択して **↺ 選択した行をやり直す** → もう一度「補完を実行」
- 🟢確定済みの行は再実行してもスキップされます(⚠エラーの行だけは自動で再実行)

## 判定の仕組み

候補ごとに 0〜100 点を付け、**80点以上かつ2位と15点以上の差**があれば🟢確定にします。

| 手がかり | 点数 |
|---|---|
| 社名が完全一致(株式会社などを除いて比較) | +70 |
| 社名が部分一致 / 類似 | +30〜60 / 最大+50 |
| 同名の営業中法人が全国で1社だけ | +15 |
| HPに法人番号が載っている(1つだけなら) | +70(複数なら+40) |
| HPの郵便番号が一致 | +15 |
| 都道府県が一致 / さらに市区町村も一致 | +15 / +10 |
| 法人格(株式会社・有限会社など)が一致 / 不一致 | +5 / −10 |
| 閉鎖済みの法人 | −30 |

## 開発者向け

```
src/        ソース(ファイルごとに役割を分割)
dist/       Apps Script に貼り付ける結合済みファイル(npm run build で生成)
test/       Node.js 上で GAS の外部呼び出しをモックしたテスト
```

```
npm run build   # src → dist を生成
npm test        # テスト(dist が最新かも確認)
```

clasp を使う場合は `src/` をそのまま `rootDir` にして push できます。

## 注意

- 法人番号の取得には国税庁「法人番号システム Web-API」を利用しています。利用規約に従い、サイドバーに次の文言を表示しています:
  「このサービスは、国税庁法人番号システムのWeb-API機能を利用して取得した情報をもとに作成しているが、サービスの内容は国税庁によって保証されたものではない。」
- HPの読み取りはベストエフォートです(JavaScriptで描画されるサイトなどは読めないことがあります)。
